# -NSE-Market-Hub
**NSE Market Hub — Nairobi Bulls &amp; Bears**  A real-time stock market dashboard for Kenyan investors, powered by the **Nairobi Securities Exchange (NSE)**. It offers live market data, AI-driven analysis, and instant Discord alerts.  **Coverage:**  * 🇰🇪 **NSE Kenya**: 12 listed companies including Safaricom, Equity, KCB, EABL, BAT
